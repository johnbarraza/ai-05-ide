# Handwritten derivation

This folder contains the student's original one-page handwritten derivation:

- [`derivation.pdf`](derivation.pdf): original file contributed on branch `ttt`.
- [`derivation.jpg`](derivation.jpg): rendered copy of the same page, used only to display it in the presentation.

The page uses a **two-human-type discrete setup**, low knowledge \(L\) and high knowledge \(H\), plus AI capability \(a=z_{AI}\). It records:

1. the setup \(0<z_L<z_H<1\), \(0<h<1\), and the span condition
   \[
   h n_L(1-z_L)=1
   \quad\Longrightarrow\quad
   n_L=\frac{1}{h(1-z_L)};
   \]
2. the pre-AI human hierarchy and its zero-profit accounting;
3. the autonomous-AI wage
   \[
   w_L^A=a[1-h(1-z_L)];
   \]
4. the bottom-winner threshold
   \[
   w_L^A>w_L^0
   \iff
   a>\frac{w_L^0}{1-h(1-z_L)};
   \]
5. the non-autonomous comparison \(w_L^N=a\) and the autonomy wedge
   \[
   w_L^N-w_L^A=a h(1-z_L)>0.
   \]

This is a transparent finite illustration, not a replacement for the paper's continuum equilibrium. Its point is the same as the required Proposition 5/6 comparison: autonomy changes the feasible organizational role and who receives the AI rent, while **capability** determines whether the bottom-winner or adoption threshold is crossed.
